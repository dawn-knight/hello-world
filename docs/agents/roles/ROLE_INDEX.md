# Role Index (Game Dev Team)

Use this as a menu of roles. Each role has a reusable agent prompt under `docs/agents/prompts/`.

## Core (most projects)

- **Producer / Scheduler**: planning, dependencies, slice breakdown, scope control  
  Prompt: `docs/agents/prompts/producer-scheduler.md`
- **Game Director / Creative Director**: creative pillars, cohesion, final taste calls  
  Prompt: `docs/agents/prompts/game-director-creative-director.md`
- **Technical Lead / Architect**: architecture, core technical decisions, performance risk  
  Prompt: `docs/agents/prompts/technical-lead-architect.md`
- **Gameplay Programmer**: player mechanics, controls feel, gameplay systems implementation  
  Prompt: `docs/agents/prompts/gameplay-programmer.md`
- **UI/UX Designer**: HUD/menus, interaction flows, accessibility, input navigation  
  Prompt: `docs/agents/prompts/ui-ux-designer.md`
- **Art Director**: style guide, visual coherence, art quality bars and feedback  
  Prompt: `docs/agents/prompts/art-director.md`
- **3D Environment Artist**: modular kits, props, environment dressing within budgets  
  Prompt: `docs/agents/prompts/artist-3d-environment.md`
- **3D Character Artist**: characters, topology/UVs/materials aligned to rig/perf constraints  
  Prompt: `docs/agents/prompts/artist-3d-character.md`
- **Animator**: animation clips, timing, state transitions, event hooks  
  Prompt: `docs/agents/prompts/animator.md`
- **Technical Artist**: pipelines, shaders/materials, asset validation, art performance  
  Prompt: `docs/agents/prompts/technical-artist.md`
- **Audio Designer / Composer**: SFX/music, mix, integration events, loudness targets  
  Prompt: `docs/agents/prompts/audio-designer-composer.md`
- **QA Lead**: test plans, repro, regression, verification of acceptance criteria  
  Prompt: `docs/agents/prompts/qa-lead.md`
- **Build / Release Engineer**: CI, packaging, versioning, release validation  
  Prompt: `docs/agents/prompts/build-release-engineer.md`
